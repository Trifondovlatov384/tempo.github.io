# Скрипты

- **sync-feed.sh** — ручной запуск синхронизации фида (вызов `GET /api/feed/sync`). Использование: `./scripts/sync-feed.sh` или `./scripts/sync-feed.sh http://your-server:3000`.

Остальные `.sh` в корне проекта (deploy.sh, rebuild.sh, start.sh, update-server.sh) относятся к развёртыванию на сервере и при необходимости можно оставить или удалить по вкусу.
